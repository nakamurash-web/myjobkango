# Go-Live チェックリスト（beyond で本番公開する手順）

「HTMLを貼り付けたら実施できる？」への答え →
**仕組み（KW出し分け）は貼り付けただけで動くが、本番として成立させるには下記の差し替え・設定が必須。**

---

## ステップ0: まず beyond で script が通るか確認（最重要）
beyond のHTMLエディタが生の `<script>` を通すかはアカウント設定で異なる。

1. `nurse-lp-demo.html` の中身を beyond のHTMLエディタ版記事に貼り付け
2. プレビューURLの末尾に `?st=看護師 夜勤なし&debug=1` を付けて開く
3. **左下にデバッグパネルが出れば script はOK** → ステップ1へ
4. 出なければ script が除去されている → JSを beyond の「タグ設定／カスタムタグ」枠に移し、HTMLには `<style>` とマークアップだけ残す運用に切替

---

## ステップ1: 必須の差し替え（これが無いと本番にならない）

- [ ] **アフィリンク**: `https://example.com/affiliate/...`（全4箇所）を実際のASP遷移URLに差し替え
      → `?debug=1` のパネルで赤（要差替）が消えることを確認

## ステップ2: 計測タグの設置

- [ ] GA4（`G-XXXXXXX`）
- [ ] Google Ads（`AW-XXXXXXX`）/ Yahoo広告（`yjtag`）

> beyond の「タグ設定」に入れるか、HTMLの該当箇所に直書きするか、どちらでも可。

## ステップ3: 広告側の設定（出し分けの発火条件）

- [ ] **ファイナルURL / トラッキングテンプレート**を `{lpurl}?st={keyword}` に
      （必要に応じ `&area=○○` `&grp=○○`）
- [ ] 広告グループ＝意図ごとにKWを分割し、**除外KW（ネガティブKW）**で意図純度を上げる
- [ ] `gclid` 等が付与される設定（自動タグ設定ON）を確認
